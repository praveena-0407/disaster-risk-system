# 🌍 Disaster Risk Prediction System

An AI-powered web application that predicts disaster risks such as **floods** and **cyclones** using machine learning and image classification. Built with **Streamlit**, this project provides an interactive interface for real-time risk analysis.

---

## 🚀 Features

* 🌊 Flood risk prediction
* 🌪️ Cyclone detection using image classification
* 📊 Overall risk analysis (Low / Medium / High)
* 🧠 Machine Learning-based predictions
* 💻 Interactive UI using Streamlit

---

## 🛠️ Tech Stack

* Python
* Streamlit
* Scikit-learn
* CNN (Deep Learning)
* NumPy, Pandas

## ⚙️ Installation & Setup

### 1. Clone the repository

```
git clone https://github.com/praveena-0407/disaster-risk-system.git
cd disaster-risk-system
```

### 2. Install dependencies

```
pip install -r requirements.txt
```

### 3. Run the application

```
streamlit run app.py
```
